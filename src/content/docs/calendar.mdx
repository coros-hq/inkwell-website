The calendar is a private weekly planner. Use it for appointments, deadlines and time-blocking your week.

## Turn the calendar on

The calendar is optional and off by default.

1. Open **Settings** at the bottom of the sidebar.
2. Go to **Features**.
3. Switch on **Calendar**.

A **Calendar** link now appears under **Quick links** in the sidebar.

## Read the week

The week runs Monday to Sunday. Hours run down the left, and today's column is highlighted. Use the previous and next arrows to change week, or click **Today** to come back to this one. The grid opens near the morning, or just before the current time, rather than at midnight.

## Add an event

- **Drag across empty space** in a day's column to create an event for that range. A plain click makes a one-hour event starting at that slot.
- Click the **+** on a day header (**Add to this day**) to add one without a time.

Each event has a title (**What are you planning?**), a start time, an optional end time, an optional last day for events that span several days, a colour and **Add details…** notes. Times snap to 15 minutes. Choose **All day** as the start to leave the time out.

Click an event to open its details beside the week. Tick its checkbox to mark it done, or use the trash button to delete it.

## Move and resize events

| To | Do this |
| --- | --- |
| Move an event | Drag the card to another time or day. |
| Change its start or end time | Drag the top or bottom edge of the card. |
| Stretch it across days | Drag the handle on an all-day card. |
| Reorder all-day cards | Drag one before another in the all-day row. |

Events with a start time sit in the hour grid at that time. Events that overlap share the width of the column side by side. Events without a time live in the all-day row, and multi-day events are bars across the days.

## Find events

Events appear in [search](/docs/search/). Search matches an event's title and notes. Picking one opens its week and its details.

## Sync with the macOS Calendar app

On a Mac, the calendar can sync both ways with the Calendar app, and so with every account added to it, such as iCloud and Google.

1. Open the **Calendar** page and click **Sync** at the top.
2. Allow inkwell to access your calendars when macOS asks.
3. Under **Calendars to show**, choose which calendars appear in the planner. New calendars are included unless you switch them off.

Events from the calendars you chose now appear in the week, from about three months back to a year ahead. Changes you make to one of them in inkwell are written back to its calendar. Events you create in inkwell go to a calendar named **Inkwell**, so they show up in the Calendar app too. Click **Sync** again to refresh.

- If an event changed on both sides since the last sync, the Calendar app's version wins.
- Recurring events, events that run past midnight and events in read-only calendars appear in inkwell but can't be edited there.
- Sync is only available in the macOS app. You can change the connection later in **Settings → Features**, next to **Calendar**.

## Where your calendar is saved

The calendar is saved on your computer, not inside any vault, so the same calendar shows whichever vault is open. It is never synced to GitHub or shared with a [team vault](/docs/collaboration/). The only sync is the optional one with the macOS Calendar app, described above.

## Unreleased

### Added

- **Calendar sync with macOS.** On a Mac, the calendar can sync both ways with the Calendar app and every account in it, including iCloud and Google. Click **Sync** at the top of the Calendar, choose which calendars to show, and events you create in inkwell go to an **Inkwell** calendar. See [Calendar](/docs/calendar/#sync-with-the-macos-calendar-app).
- **Nested notes.** A note can now have child notes, to any depth, like a GitHub issue with sub-issues. Hover a note in the list and click **+** to add a sub-note, or drag one note onto another to nest it. Children are indented under their parent and can be collapsed, and the editor's breadcrumb shows the full path. Deleting a parent deletes everything nested under it, and moving a parent to another folder moves its children too. See [Nested notes](/docs/nested-notes/).
- **Brainstorm: add and move nodes in the mind map.** A toolbar and on-node **+** buttons add children and siblings with the mouse, and you can drag a node onto another to re-parent or reorder it. The outline has an **Add point** button. See [Brainstorm](/docs/brainstorm/#add-and-edit-nodes).
- **Brainstorm: links.** Connect any two nodes with a labelled arrow. Select a node, press <kbd class="kbd">L</kbd> and click the other node. See [Brainstorm](/docs/brainstorm/#link-related-ideas).
- **Claude can manage your calendar and boards.** The built-in MCP server now covers calendar events and Kanban boards and tasks, not just notes. See [Claude (MCP)](/docs/claude-mcp/).
- **Create tags from notes and folders.** Hover a note or folder, click the **tag** icon and type a name to create a tag and apply it in one step. See [Organising notes](/docs/organising-notes/#create-a-tag).
- **Vault switcher in the sidebar.** Click the vault name at the top of the sidebar to switch vaults, open a folder or create a new vault. See [Vaults and your files](/docs/vaults-and-files/#switch-vaults).
- **Suggested vault on first launch.** A fresh install offers to create a vault at `Documents/Inkwell/Vault`, or you can change the location. See [Getting started](/docs/getting-started/).
- **XMind import and export.** Import a `.xmind` file as one brainstorm per sheet, or export a brainstorm to `.xmind`. See [Brainstorm](/docs/brainstorm/#import-and-export-xmind).

### Improved

- **New flat design.** The sidebar, note list and tag badges lose their heavy borders and use flat colour fills. The light/dark toggle at the top of the sidebar is gone; change **Mode** in **Settings → Appearance**.
- **Tag filtering shows everything that matches.** Clicking a tag lists the matching folders and notes under their full folder path, and opening one highlights it in the folder tree. See [Organising notes](/docs/organising-notes/#filter-by-tag).
- **Notes shows all notes.** Clicking **Notes** in the sidebar's quick links clears the folder selection and lists every note, not just those outside folders.
- Tag badges no longer show a `#`.
- Long tag lists in right-click menus now scroll, and menus stay inside the window, so **Delete** is never cut off.
- The note list's tabs toggle now uses a tabs icon instead of a stacked-squares icon that looked like a hierarchy.

### Fixed

- **Reopening after closing the window.** On macOS, closing inkwell with the red close button only hides it. Clicking the Dock icon now brings the window back.

A maintenance release with no user-facing changes.

## 2.1.0

### Added

- **Calendar.** A private weekly planner. Turn it on in **Settings → Features → Calendar** and a **Calendar** link appears in the sidebar. Hours run down the side: drag across empty space to create an event, drag a card to move it, and drag its top or bottom edge to change its time. Events without a time sit in an all-day row where you can reorder them, and multi-day events are bars across the days. Events have a colour, notes, and a done checkbox, and they show up in search. Your calendar stays on your computer and is never synced or shared. See [Calendar](/docs/calendar/).
- **Command palette.** <Kbd keys="mod+shift+p" /> opens search on the new **Shortcuts** tab, which lists every shortcut. Pick one to run it. See [Search](/docs/search/#the-shortcuts-tab).
- **Focus mode.** <Kbd keys="mod+shift+d" /> hides everything except the open note. Press <Kbd keys="esc" /> to come back. See [Writing](/docs/writing/#focus-mode).
- **Keyboard navigation for the sidebar.** <Kbd keys="mod+0" /> moves focus to the folder tree and <Kbd keys="mod+9" /> to the note list. Use the arrow keys, <Kbd keys="home" /> and <Kbd keys="end" /> to move, <Kbd keys="enter" /> to open, <Kbd keys="f2" /> to rename and <Kbd keys="esc" /> to return to the editor.
- **Single / split mode shortcut.** <Kbd keys="mod+shift+e" /> switches the open note between Normal and Markdown mode.
- **Nested lists.** <Kbd keys="tab" /> and <Kbd keys="shift+tab" /> nest and un-nest bullet and numbered items. Nested numbered items get outline numbers like `1.2`, and <Kbd keys="enter" /> on one starts the next (`1.3`).
- **Images and Excalidraw in Draw.** Paste or upload images onto the canvas, and paste Excalidraw content (or add a `.excalidraw` file) to convert it into canvas shapes. Shapes with no equivalent, like diamonds and frames, are approximated. See [Canvas](/docs/canvas/#images-and-excalidraw).
- **Catppuccin themes.** Catppuccin Mocha (dark) and Catppuccin Latte (light). See [Themes and appearance](/docs/themes/).
- **Portable Windows build.** `inkwell_*_x64-portable.zip` runs without an installer or admin rights. A portable copy doesn't update itself: when an update is available, the update button opens the releases page so you can download the new zip. See [Getting started](/docs/getting-started/#windows-portable).
- A new empty state in the note list: **A blank page awaits**, with a **New note** button.

### Improved

- **Toggle Sidebar** is now <Kbd keys="mod+shift+b" />, because <Kbd keys="mod+b" /> is Bold in the editor. If you had never changed it, the new default applies automatically.
- **Search** shows a snippet around the first match in a note's content, so a content hit doesn't look like a stray title match.
- Links to websites and email addresses open in your default browser.
- Large notes are saved a moment after you stop typing instead of on every keystroke, so typing stays smooth. Pending changes are saved when you switch vaults or close the window.
- The editor toolbar scrolls sideways in narrow panes instead of clipping its buttons.

## 2.0.1

### Added

- **Trash.** Deleting a note or folder now moves it to **Trash** instead of erasing it. Open **Trash** in the sidebar to **Restore** an item to its original location or delete it forever, or use **Empty trash**. See [Organising notes](/docs/organising-notes/#delete-notes-and-folders).

### Improved

- **Safer saving.** Notes and data files are written to a temporary file first and then swapped in, so a crash or power cut mid-save can't leave a half-written file. Overlapping saves of one file are queued so they can never land out of order.
- **Automatic backups.** Data files in `.inkwell` keep a `.bak` of the last good version. If one is damaged, inkwell keeps the damaged copy as `.corrupt-<timestamp>` and loads the backup instead of starting empty. See [Vaults and your files](/docs/vaults-and-files/#the-hidden-inkwell-folder).
- If a save fails (a full disk, a read-only folder, missing permissions), inkwell now tells you instead of failing silently.

## 2.0.0

### Added

- **Folder tags.** Create tags with a name and colour from the **+** in the new **Tags** section of the sidebar. <Kbd keys="mod" /> + click one or more folders and click a tag, or right-click a folder and toggle tags in its menu. Tagged folders show coloured dots on the right of the row, and clicking a tag with nothing selected filters the sidebar to its folders. Tags can be renamed, recoloured or deleted, and the change applies to every folder using them. They're stored per vault in `.inkwell/folders.json`. See [Organising notes](/docs/organising-notes/#folder-tags).
- **Group by tag** for folders. The folder context menu option now groups both sub-folders and notes under their first tag, with collapsible `#tag` headers and an **Untagged** group last.
- **Search by tag.** In <Kbd keys="mod+k" />, `#name` searches tags only. A plain query also matches notes inside a tagged folder, including parent folders. See [Search](/docs/search/).
- **Optional Brainstorm.** Brainstorm is now a toggle in **Settings → Features**, off by default like Canvas. When off, the sidebar link and the `/brainstorm` slash command are hidden. Existing brainstorm data and embeds are untouched. See [Brainstorm](/docs/brainstorm/).
- **New themes** in **Settings → Appearance**: Solarized Osaka (dark), Noir Ember (dark) and Ivory Ember (light), each with its own code-block syntax colours. See [Themes and appearance](/docs/themes/).

### Improved

- **Sidebar reorganised** into Quick links (Notes, Board, Brainstorm and Draw when enabled), Folders, Tags and Open Files. The folder tree has a capped height and scrolls inside, so Tags stay visible. The active quick link is an accent pill, and section headings are quieter sentence case.
- **Glass mode (macOS)** is polished: translucent hairline dividers, soft translucent hover and selected highlights, a faint top sheen, and the editor as a rounded floating card. On light themes the glass keeps a minimum opacity (about 88% for the editor card) so wallpaper colours don't show through text.
- The **Search** button in the sidebar now has a filled background.
- **Syntax highlighting** has separate token colours for types and classes, and for operators and punctuation. Other themes look the same as before. The rendered preview now colours function and class names separately.

### Fixed

- **Draw in light and dark themes.** Near-white or near-black strokes, fills and shape text now adapt to the current theme when drawn instead of becoming invisible. Saved drawings are not modified, so they look right in both themes. Sticky notes and clearly coloured shapes are unchanged.
- The **Draw default font** is now the hand-written font everywhere it previously fell back to sans (sticky notes, older shapes, templates and category elements). Explicit font choices are kept.
- **Vim mode:** the `--NORMAL--` status bar at the bottom of the editor is gone. The `:` and `/` prompts still appear when used.

## 1.0.4

### Added

- Code blocks in the single-pane editor have a **Copy** button on hover. It copies the code without the fences.
- **Editor width** in **Settings → Editor** controls the side space around your note text, in both the editor and the preview. See [Settings](/docs/settings/#editor).
- Obsidian-style `[[wikilinks]]` are clickable in the editor and the preview. See [Linking notes](/docs/linking-notes/#wikilinks).
- In the single-pane editor, a plain click on a note link or wikilink opens the note. If your cursor is already on that line, the click places the caret so you can edit the link.
- Note links in the editor show a pointer cursor on hover.

### Fixed

- Closing the window while in macOS full screen no longer leaves a black screen. The window leaves full screen first, then hides.
- Notes no longer gain extra blank lines at the top each time they reload. Existing notes with leftover blank lines are cleaned up when you open them.
- Files moved or copied into your vault from Finder now appear without restarting the app.
- Task checkboxes now show in the single-pane (Normal) editor instead of raw `[ ]` and `[x]`.
- Checked tasks show strikethrough, dimmed text.
- Removed the non-functional **…** button from the editor toolbar.
